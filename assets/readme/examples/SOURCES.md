# README gallery provenance

These are snapshots of the actual upstream SVGs, not reconstructions or newly generated variants. `sources.json` records each repository, original path, source link, and Git blob SHA. The Chinese README embeds the Chinese versions; the English README embeds the English versions.

- **fly-favicon**: a banner generated with the skill and refined in the user-referenced lettering task. Source: [fly-favicon README](https://github.com/flyl1u/fly-favicon). Repository artwork uses its [MIT license](https://github.com/flyl1u/fly-favicon/blob/main/LICENSE); the Chinese outlined lettering uses Xiaolai under SIL OFL. Its notice is included in [OFL-Xiaolai.txt](../../lettering/OFL-Xiaolai.txt).
- **fly-brief**: the original banner-authoring workflow from which the skill was extracted. Source: [fly-brief README](https://github.com/flyl1u/fly-brief). The repository is [MIT licensed](https://github.com/flyl1u/fly-brief/blob/main/LICENSE). Agent marks came from LobeHub Icons; its unmodified [MIT notice](../../style-references/LobeHub-LICENSE.txt) is bundled. Marks remain their respective owners' marks.
- **CodexPulse**: an early style and before/after explanation reference, not a claim that this already-existing banner was generated with the later skill. Source: [CodexPulse README](https://github.com/flyl1u/CodexPulse). Its unmodified [MIT notice](../../style-references/CodexPulse-LICENSE.txt) is bundled.

The local repository [MIT notice](../../../LICENSE) also carries the project owner's copyright. Preserve the linked notices when redistributing these examples. Historical examples retain their original lettering implementation, including native SVG text where present; the skill's current publication default uses portable outlines.
